# 📊 SALES-DATA-VISUALIZATION

A clean and intuitive sales data visualization tool designed to simplify complex metrics for clients, enabling quick insights and seamless communication through clear, impactful charts.

---

## 🚀 Project Overview
This project transforms raw, complex sales data into an interactive and user-friendly Excel dashboard. Built specifically for clients and stakeholders, it automates repetitive reporting tasks and presents key performance indicators (KPIs) in the easiest way possible for quick decision-making and better communication.

---

## 🛠️ Built With & Key Features
* **Advanced Excel Methods:** Leveraged dynamic cross-sheet linking to connect multiple data sources seamlessly.
* **Pivot Tables:** Summarized large datasets to extract meaningful sales trends, regional performance, and top-selling products instantly.
* **Interactive Charts:** Visualized sales performance through engaging, easy-to-understand charts for high-level client presentations.
* **Macros (VBA):** Automated data processing and reporting workflows to save time and reduce manual errors.

---

## 📁 Repository Structure
* `Auto Sales data.xltm`: The core Excel macro-enabled template containing all data models, pivot tables, macros, and charts.
* `README.md`: Project documentation and guide.

---

## 🎯 How to Use
1. Download or clone the repository.
2. Open `Auto Sales data.xltm` in Microsoft Excel.
3. Enable macros when prompted to ensure all automated features function smoothly.
4. Explore the dashboard and interact with the charts and pivot tables to view dynamic sales insights.

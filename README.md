# 📊 SALES-DATA-VISUALIZATION

A clean and intuitive sales data visualization tool designed to simplify complex metrics for clients, enabling quick insights and seamless communication through clear, impactful charts.

---

## 🚀 Project Overview
This project transforms raw, complex sales data into an interactive and user-friendly Excel dashboard. Built specifically for clients and stakeholders, it automates repetitive reporting tasks and presents key performance indicators (KPIs) in the easiest way possible for quick decision-making and better communication.

---

## 🛠️ Built With & Key Features
* **Advanced Excel Methods:** Leveraged dynamic cross-sheet linking to connect multiple data sources seamlessly.
* **Pivot Tables:** Summarized large datasets to extract meaningful sales trends, regional performance, and top-selling products instantly.
* **Interactive Charts & Slicers:** Visualized sales performance through engaging, easy-to-understand charts and interactive slicers/timelines for high-level client presentations.
* **Macros (VBA):** Automated data processing and reporting workflows to save time and reduce manual errors.

---

## 📂 Repository Structure
* `Auto Sales data.xltm`: The core Excel macro-enabled template containing all data models, pivot tables, macros, and charts.
* `README.md`: Project documentation and guide.

## 📥 How to Download and Run the Project

Since GitHub does not run interactive Excel dashboards directly in the browser, you need to download the file to experience the fully interactive slicers, timelines, and macros. 

Follow these simple steps to set it up properly:

1. **Download the File:**
   * Click on the `Auto Sales data.xltm` file in this repository.
   * Click on the **[Download](https://github.com/gauravgurjar9660/SALES-DATA-VISUALIZATION/blob/main/Auto%20Sales%20data.xltm)** (or Raw) button to save the file to your computer.

2. **Unblock the File (Important for Macros & Slicers):**
   * Go to your Downloads folder where the file was saved.
   * Right-click on `Auto Sales data.xltm` and select **Properties**.
   * At the bottom of the General tab, if you see an **Unblock** checkbox (Security: This file came from another computer...), check the box.
   * Click **Apply** and then **OK**. *(This ensures Windows allows macros and advanced controls to run).*

3. **Open and Enable Content:**
   * Open the file in **Microsoft Excel**.
   * When the file opens, you will see a yellow security warning bar at the top (Protected View / Macros Disabled).
   * Click on **Enable Content** or **Enable Editing**. 

Now your dashboard is fully ready! You can freely use the slicers, timeline, and interactive charts.
